# ONE TRIP — M6A.1 Long-Term Depth Addition

This document extends Option D without changing the current short graybox travel test.

## Locked direction

The current ~528-stud playable runway is a rapid-test footprint only.

It is **not** the final intended warehouse length.

The final M6 warehouse should create the emotional read:

> How far does this warehouse actually go?

The player should understand that progression moves deeper away from home, but should not stand near the bays and immediately read a final back wall.

## Section depth strategy

Do not increase every section equally just to make the number bigger.

Final depth should be distributed by progression role:

- Receiving — compact
- Appliances — compact
- Furniture — expanded
- HeavyGoods — expanded
- Industrial — substantially deeper
- Secure — substantially deeper

Exact final stud counts remain intentionally unlocked until Option D runtime testing establishes the right travel/competition baseline.

## What added depth must buy

Every meaningful increase in depth must add some combination of:

- cargo opportunities,
- shared player encounters,
- rarity sightings,
- greed decisions,
- stronger section transitions,
- stronger commitment,
- more spatial identity.

Do not add empty runway whose only gameplay is holding W.

## Mobility relationship

Advanced Mobility should make previously mastered early sections quick to traverse while unloaded/light.

Dangerously loaded returns must remain meaningfully slower and continue to expose the player to Sway, Load Pressure, instability and collapse risk.

Do not use Mobility as an excuse for boring empty distance.

## M6A.1 graybox implementation

For current testing, the six gameplay sections still end at the existing Option D test boundary so travel/economy measurements remain comparable.

However the obvious `SecureBackWall` is removed for Option D.

Instead:

- the current gameplay boundary is invisible and exists only beyond the playable Secure section,
- a non-playable warehouse shell continues visually another 280 studs,
- repeating primitive columns/overhead beams imply further infrastructure,
- side walls/floor continue beyond Secure,
- the preview contains no loot and no new gameplay,
- existing future-expansion markers remain reserved behind Secure.

This is a graybox depth cue, not final art.

## Final environment-art handoff

When macro geometry is later locked, final environment art should obscure the endpoint using warehouse language rather than a giant visible wall:

- repeating columns,
- overhead beams,
- distant lighting,
- machinery silhouettes,
- freight structures,
- atmospheric depth,
- section architecture,
- gantries,
- distant signs,
- controlled sightline obstruction.

The deepest currently playable area should still imply that the larger facility continues.

## Expansion rule

Future playable depth should extend behind/beyond Secure or through believable continuation/annex points.

Do not implement those future gameplay areas during M6A.1.

## Final requirement

**The player should understand the direction of progression without being able to immediately see the end of it.**
